# Phase 1 — Research and data audit checklist

- [ ] Confirm whether the official challenge portal still permits account/data access.
- [ ] Read the applicable terms before downloading or reusing challenge data.
- [ ] Identify a lawful source of water-quality labels.
- [ ] Identify public climate/terrain/satellite sources and their licenses.
- [ ] Record measurement units, sampling dates, coordinates, and detection-limit conventions.
- [ ] Estimate file sizes before downloading.
- [ ] Confirm the dataset is suitable for geographic holdout evaluation.
- [ ] Update `reports/data_sources.md` with verified details.

**Exit criterion:** We know which data we can lawfully use, what each field means, and whether the project can be reproduced without restricted competition files.
